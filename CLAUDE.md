# CLAUDE.md — правила для Claude/Cowork

Импортируй и соблюдай `AGENTS.md`.

## Режим работы
Перед кодом:
1. Просмотри структуру проекта.
2. Найди связанные файлы.
3. Дай короткий план.
4. Вноси минимальные изменения.
5. В конце дай изменённые файлы и способ проверки.

## Особо важно
- Не добавлять backend, если MVP можно проверить локально.
- Не превращать MVP в большую LMS.
- Не использовать AI для финальной проверки простых математических ответов.
- Не проектировать рекламу за ошибку.
- Не обещать поступление в школу.
- Все спорные допущения записывать явно.
