# CHANGELOG (для тестеров)

Дата: 2026-05-25

---

## Что работает прямо сейчас

### Учебный цикл
- После ошибки сразу появляется короткое правило по навыку
- Можно выбрать формат объяснения: **Коротко (1 шаг)** или **Подробно (3 шага)**
- После ошибки система даёт похожий, но чуть легче вопрос для закрепления
- В начале каждой темы — якорный пример, чтобы вспомнить базовый ход решения
- XP за правильные ответы считается и сохраняется в истории сессии

### Адаптация
- Миссия дня подбирается по слабому навыку: новый / ремонт / закрепление / поддержка / вызов / boss
- Навыки имеют 7 статусов: new → learning → stable → mastered / challenge_ready / needs_review / blocked
- Повторение ошибочных вопросов по расписанию (spaced repetition)

### Клавиатурная навигация
- Клавиши `1/2/3/4` — выбор варианта
- `Enter` / `Пробел` — проверить / перейти дальше

### Для родителя
- Дашборд: вывод за 10 секунд — как дела, где риск, что делать
- До 3 слабых навыков с объяснением причины и следующим шагом
- Переход прямо в урок по слабому навыку
- Динамика точности по слабому навыку (sparkline за 7 дней)

---

## Что проверить тестерам

1. **После ошибки:** появляется объяснение → переключение Коротко/Подробно работает → следующий вопрос похожий и немного легче
2. **Миссия:** в начале урока показывается тип миссии и цель (N из 10 правильно)
3. **SkillMap:** у навыков правильные статусы после нескольких сессий
4. **Родительский дашборд:** после 2–3 сессий появляются слабые навыки и рекомендация
5. **Повторение:** через день после ошибок в ReviewSession появляются нужные вопросы
6. **Язык:** нет смешения RU/ES в одном экране

## Известные ограничения

- Reward dispatch (XP → карточки Football Academy) не замкнут — карточки начисляются, но не выдаются в UI
- В ReviewSession нет итогового breakdown по навыкам (только общий счёт)
- Заблокированный навык не объясняет, что именно нужно пройти сначала
