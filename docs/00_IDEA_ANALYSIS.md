# 00 — Анализ идеи

## Суть одним предложением
Цифровая подготовка по математике для детей 10–13 лет в Аргентине: ребёнок читает правило, решает задания, получает простое объяснение, а родитель видит реальный прогресс и усилие.

## Сильные стороны
1. Боль конкретная: ребёнок слаб в математике перед secundaria/ingreso.
2. Есть понятные аналоги: тетради, подготовительные курсы, репетиторы.
3. Канал распространения дешёвый: WhatsApp/Telegram/Facebook-группы родителей.
4. Темы повторяются ежегодно, контент можно переиспользовать.
5. Ценность выше бумаги: приложение даёт аналитику и повторение ошибок.

## Слабые места
1. Нельзя копировать материалы подготовительных школ или тетрадей.
2. Нельзя обещать гарантированное поступление.
3. Реклама за ошибку выглядит как наказание и создаёт риск для детского продукта.
4. Слежка за экраном должна быть мягкой: считать активное время, а не “контролировать ребёнка”.
5. Родители платят только если быстро видят пользу.

## Лучшее позиционирование
**Домашний математический тренажёр для 6°–7° grado: 20 минут в день, простые объяснения и понятный отчёт для семьи.**

## Продуктовая формула
Правило → 3 примера → 10 заданий → разбор ошибок → отчёт родителю.

## Рабочее название
Лучшее: **Durillo**.
Альтернативы: MateIngreso, PuenteMate, MatePuente, MateFácil Ingreso, Mate en 20.
