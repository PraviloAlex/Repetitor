# Football Academy Spec — Durillo

Дата: 2026-05-23
Статус: активная разработка (Stage Game-1)

Этот документ дополняет `GAME_LAYER_SPEC.md`. `GAME_LAYER_SPEC` описывает спокойный
учебный слой (миссия дня, XP, streak, бейджи). Этот документ описывает
**коллекционный футбольный слой** поверх него.

## 1. Принцип

Футбол — это оболочка, а не игра вместо учёбы. Правило, которое нельзя нарушать:

> Каждая награда выдаётся только за реальное учебное действие.
> Карточки и игроки нельзя купить и нельзя получить просто за вход.

Порядок ценности продукта: качественные вопросы и объяснения → прогресс →
коллекция. Футбол усиливает мотивацию, особенно для Аргентины и в период
мундиаля, но не заменяет учебный движок.

Все игроки — **вымышленные**. Реальные футболисты, клубы и лиги не используются
(см. `AGENTS.md`, пункт 2).

## 2. Слой карточек-вопросов

Каждый вопрос получает два опциональных поля, которые делают его «карточкой».

### 2.1. Редкость (`rarity`)

| Редкость | Смысл | Рамка |
|----------|-------|-------|
| `common` | базовое правило | серо-синяя |
| `rare`   | правило + лёгкая ловушка | синяя |
| `epic`   | несколько правил вместе | фиолетовая |
| `mythic` | задание на объяснение | золотая |
| `legend` | boss-задача / задача дня | чёрно-золотая |

Если `rarity` не задана явно, она выводится из `difficulty`:
1 → common, 2 → rare, 3 → epic, 4 → mythic, 5 → legend.
Это позволяет не переписывать вручную все 180 вопросов.

### 2.2. Тип карточки (`cardType`)

| Тип | Назначение |
|-----|-----------|
| `training` | обычное закрепление (по умолчанию) |
| `trick`    | ловушка на типичную ошибку |
| `speed`    | задание на скорость |
| `explain`  | выбрать правильное объяснение |
| `visual`   | задание с картинкой/схемой |
| `boss`     | итоговое сложное задание темы |
| `comeback` | задание, собранное из ошибки ребёнка |

Поля опциональны: старые вопросы продолжают работать без них.

## 3. Футбольная академия

### 3.1. Игроки

В Stage Game-1 — 10 вымышленных игроков. Каждый открывается за освоение навыка,
а не за время или паки. Состав 1-3-3-3 (вратарь, защита, центр, атака).

Игрок описывается полями: `id`, `name`, `number`, `position` (GK/DEF/MID/FW),
`rarity`, условие открытия `unlock` (тема + точность + минимум ответов),
`specialty` (особенность — пока флавор-текст, не игровая механика).

Условия открытия привязаны к `topicAccuracy` из локального прогресса:
от «провёл первую сессию» (common) до «70%+ во всех 6 темах» (legend-капитан).

### 3.2. Поле

Отдельный экран `Academia` (`/academy`):

- зелёное поле (SVG: центральный круг, линия, штрафные);
- открытые игроки стоят на своих позициях карточкой с рамкой редкости;
- закрытые — силуэт с подсказкой «как открыть»;
- заголовок: `Plantel: N / 10`.

На мобильном — отдельный экран (mobile-first). На десктопе поле может позже
переехать в правую панель рядом с уроком — это отложенное улучшение, не Stage 1.

### 3.3. Parent-safe

Родителю важно, что футбол не вытесняет учёбу. Текст для родителя:

```text
La colección de futbolistas se desbloquea solo con práctica real.
No hay compras dentro de la zona del niño.
```

```text
Коллекция футболистов открывается только за реальную практику.
В детской зоне нет покупок.
```

## 5. Главный риск

Переиграть в игру. Если ребёнок жмёт ради награды, не понимая математику —
продукт стал слабее. Контрмеры: легендарные награды только за понятный учебный
подвиг (серия дней, 90%+ в теме, первый идеальный boss), мягкий streak без
давления, никакой рекламы и покупок в детской зоне.

## 6. Процедурные варианты заданий (генератор)

Проблема: статичных вопросов конечное число, ребёнок видит одни и те же.
Решение: часть карточек строится не из готового текста, а из **шаблона логики**.

Шаблон хранит логику (например «сложение двух чисел»), а числа подбираются
алгоритмом при каждом запуске. Так `10+1` в одной сессии становится `8+3` или
`2+9` в другой — суть та же, цифры разные.

Свойства генератора:

- одна и та же логика даёт разные числовые варианты;
- внутри сессии один сгенерированный вопрос не повторяется (seed по индексу);
- сложность шаблона задаётся диапазонами чисел (`difficulty` влияет на диапазон);
- ответ и объяснение вычисляются из чисел, AI для проверки не используется
  (см. `CLAUDE.md`: простую математику не проверять через AI);
- генератор детерминирован при заданном seed — это нужно для review-очереди,
  чтобы ребёнок повторил тот же вариант, а не другой.

Шаблон описывается полем `generator` у вопроса (опционально). Если оно есть,
текст/ответ/объяснение строятся из него; если нет — вопрос статичный, как раньше.
Статичные и генерируемые карточки сосуществуют.

Stage Game-1 включает первые шаблоны для темы `operaciones` (сложение,
вычитание, умножение) как доказательство механики.

## 7. Явные допущения (Stage Game-1)

- XP-система в коде ещё не реализована, поэтому `specialty` игрока — флавор-текст,
  а не активный бонус. Когда XP появится, бонусы станут мягкими (+1 подсказка,
  +5% XP), без «игрок решает за тебя».
- Прогресс хранится локально (`localStorage`), синхронизации между устройствами нет.
- Открытие игроков считается из `topicAccuracy` — оно уже накапливается по сессиям.
