# 13 — Prompts for AI Agents

## Prompt — полный анализ
```text
Ты подключён к папке проекта Durillo.

Сначала прочитай README.md, AGENTS.md, CLAUDE.md и все файлы в docs/.

Задача:
1. Проанализируй проект как senior product strategist + EdTech UX designer + frontend architect.
2. Найди 10 сильных сторон.
3. Найди 15 рисков.
4. Предложи лучший MVP-формат.
5. Обнови roadmap и stage tasks, если видишь лучший порядок.
6. Не выдумывай факты о школах, законах и экзаменах.
7. Спорные допущения вынеси в ASSUMPTIONS.
Ответ на русском.
```

## Prompt — первый прототип
```text
Ты senior frontend developer.
Создай mobile-first web app Durillo.
Требования: без backend, прогресс в localStorage, 3 темы, 10 вопросов на тему, правило → вопросы → объяснения → summary, focus tracking, parent summary, интерфейс на испанском. Не делать рекламу, оплату, регистрацию, AI-chat.
В конце дай список файлов, как запустить и как проверить.
```

## Prompt — генерация контента
```text
Ты методист по математике для детей 10–13 лет.
Создай оригинальный JSON-контент для темы [TOPIC], уровень 6°–7° grado Argentina: правило, 3 примера, 30 вопросов, 5 уровней сложности, answer, explanation_es, hint_es, common_mistake, skill_tags. Не копировать учебники.
```

## Prompt — UX audit
```text
Ты senior UX designer для детского EdTech. Проверь: понятно ли ребёнку, понятно ли родителю, нет ли токсичного контроля, нет ли перегруза, работает ли на телефоне. Дай 15 UX-замечаний, 10 улучшений текста, 10 визуальных улучшений, 5 быстрых правок.
```
