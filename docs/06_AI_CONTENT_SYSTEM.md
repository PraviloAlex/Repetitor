# 06 — AI Content System

## Роль AI
AI помогает генерировать черновики заданий, объяснения и варианты похожих примеров. Финальную проверку ответов должен делать код или человек.

## Pipeline
1. Выбрать тему.
2. Написать learning objective.
3. AI генерирует 30–50 заданий.
4. Скрипт проверяет ответы, где возможно.
5. Человек проверяет контент.
6. Задания получают `verified: true`.

## Prompt для генерации
```text
Ты создаёшь оригинальные задания по математике для детей 10–13 лет в Аргентине.
Тема: [TOPIC]
Уровень: 6°–7° grado
Язык: español rioplatense нейтральный.
Количество: 30.
Типы: multiple_choice, numeric_input, true_false.
Требования: оригинальные задания, бытовые контексты Аргентины, правильный ответ, explanation_es, hint_es, difficulty 1–5, common_mistake, skill_tags. Не использовать бренды, не копировать учебники, не унижать ребёнка.
Верни JSON array.
```

## Prompt для ошибки
```text
Объясни ошибку ребёнку 11–12 лет на испанском Аргентины. Максимум 70 слов. Дружелюбно. Объясни один главный шаг. Не используй слова “tonto”, “mal”, “fácil”. Заверши похожей подсказкой.
```

## Чеклист качества
- ответы правильные;
- объяснение до 90 слов;
- нет копирования;
- нет токсичного тона;
- есть уровни сложности;
- есть типичные ошибки;
- есть повторение после ошибки.
