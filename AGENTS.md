# AGENTS.md — правила AI-агентов

## Роль проекта
Мы строим образовательный MVP для Аргентины: математика для детей 10–13 лет, переход primaria → secundaria / ingreso.

## Язык
- Общение с владельцем: русский.
- Интерфейс продукта: испанский Аргентины.
- Файлы, код, функции: английский.

## Принципы
1. Не делать “ещё один квиз”. Делать домашний учебный инструмент.
2. Не копировать тетради, курсы, школы, PDF и платные материалы.
3. Все задания — оригинальные, но темы могут опираться на учебную программу.
4. Ошибка ребёнка = объяснение, а не наказание.
5. Не собирать лишние персональные данные ребёнка.
6. Не использовать агрессивную рекламу детям.
7. Родителю показывать прогресс и усилие, а не “слежку”.

## Definition of Done
Фича готова, если ребёнок проходит её без помощи взрослого, родитель понимает итог за 10 секунд, данные сохраняются, UI работает на телефоне, нет токсичных паттернов против детей.
